## Default Permission

手机壳主窗口能登记推送、取通知点击、检测后台限制并打开应用设置。

#### This default permission set includes the following:

- `allow-register`
- `allow-take-tap`
- `allow-clear-notifications`
- `allow-background-status`
- `allow-open-background-settings`
